# 이미지형 규격 (좌표)

출처: 카카오비즈니스 [이미지형 제작가이드](https://kakaobusiness.gitbook.io/sandbox2025/ad/bizmessage/notice-friend/content-guide/image)의 레이아웃 도판 + 같은 페이지의 공식 Sketch 템플릿(프레임 좌표로 교차 검증) + 공식 PDF 템플릿 v2.1.
상수는 `scripts/lib/spec.mjs`에 있다. 값을 바꾸면 이 문서도 함께 고친다.

## 공통

| 항목 | 값 |
|---|---|
| 캔버스 | 800x400 (2:1). 2:1이 아니거나 가로 500·세로 250 이하면 업로드 불가 |
| 형식 / 용량 | JPG, PNG / 500KB 이하 |
| 배경색 | `#F9F9F9`만 허용 (흰색·브랜드색 불가) |
| 폰트 | Spoqa Han Sans, **54pt 고정**, 자간 0 |
| 텍스트 색 | `#333333`, **Bold만** |
| 템플릿당 | 고정 이미지 1장, 이미지 클릭 링크 불가, 카카오톡 8.7.5 이상에서 노출 |
| 이미지형과 | 강조표기형 동시 사용 불가 |

폰트 파일은 공식 가이드의 `Spoqa Han Sans Regular/Bold.ttf`와 같은 이름이며, SIL OFL 1.1로 `assets/fonts/`에 번들돼 있다.

## 로고형

가로형 워드마크 또는 시그니처를 가이드 영역 가운데에 둔다.

| 항목 | 값 |
|---|---|
| 가이드 영역 | W600 x H150, 좌우 여백 100, 상하 여백 125 → `x100 y125` |
| 가로로 긴 로고 | 높이 50px 이상 |
| 짧은 로고 | 폭 260px 이상 |
| 영역을 벗어나는 형태 | 위 또는 아래에 25px 영역을 추가해 배치 (`--tall`, 근거는 도판 한 장) |
| Sketch 샘플 | 로고 이미지 `[159, 139, 482, 125]` |

## 텍스트 혼합형

좌상단 텍스트 + 우하단 아이콘/일러스트/오브젝트.

| 항목 | 값 |
|---|---|
| 텍스트 영역 | W520 x H240, `x36 y42`, **좌측 정렬** |
| 행간 / 자간 | 74 / 0 |
| 글자 수 | 최소 4자. 2줄/20자 노출 지향. 불가피하면 3줄/30자(그래도 2줄/20자처럼 보이게) |
| 아이콘 | 180x180, 우측 여백 20, 하단 여백 16 → `x600–780, y204–384`. 아이콘 상하좌우에 적절한 여백 포함해 제작 |
| 일러스트/오브젝트 | 최소 230x230, 최대 400x320. 우하단 기준(최소 영역은 우 20, 하 16). 큰 소재는 최대 영역 안에서 노출 |
| Sketch 샘플 | 아이콘 `[600,204,180,180]`, 일러스트 `[552,211,231,163]`, `[432,135,400,280]` |

렌더러 동작: 아이콘은 위 박스, 일러스트(`--art`)는 우 20·하 16 여백을 둔 380x304 영역(x400–780, y80–384)에 맞춰 우하단 정렬. `--bleed`면 모서리 기준 400x320.

## 아이콘형

상태를 아이콘으로, 짧은 텍스트로 보조.

| 항목 | 값 |
|---|---|
| 아이콘 영역 | 180x180, 상단 여백 76, 가로 가운데 → `x310 y76` (글리프는 상하좌우 여백 포함) |
| 텍스트 영역 | W460 x H68, 하단 여백 76, 가로 가운데 → `x170 y256`, **가운데 정렬** |
| 글자 수 | 최대 9자(띄어쓰기 포함), 최소 2자, 4자 노출 권장 |
| 줄 수 | 1줄 |
| Sketch | 텍스트 `[170,256,460,68]`, 이미지 `[310,76,180,180]` |

## 배송 단계(steps)형 — 근사값

공식 제작가이드 본문에는 없고, 공식 PDF 템플릿(v2.1)의 단계형 페이지에서 측정한 근사치다.

| 항목 | 값 |
|---|---|
| 안내문 | 2줄 가운데 정렬. 1줄 Regular, 2줄은 핵심 단어만 Bold. 안내문 위 여백 34 |
| 단계 아이콘 | 4개, 중심 x = 116 / 305 / 494 / 683 (간격 189), 중심 y 245, 원 지름 약 110 |
| 현재 단계 | 노랑 원 + 진한 아이콘 + 진한 라벨 / 나머지는 연회색 원 + 회색 아이콘·라벨 |
| 연결선 | 회색 점선 |
| 라벨 | 단계명, 좌우 여백 52, 하단 여백 42 |

공식 단계형은 안내문 폰트가 54pt 규정과 다르게 더 작다(약 40px). 이 유형은 검수 전 눈으로 반드시 확인한다.

## 아이콘 스타일 (공식 PSD 샘플링)

공식 PSD의 아이콘 레이어에서 측정한 값: 선 굵기 5~6px(수평 런 중앙값), 선 색 `#111111`, 포인트 색 `#FFE500`, 글리프 크기 102~144px(180 박스 안). 번들 아이콘은 글리프 132px, 선 약 6px로 맞췄다.
공식 아이콘은 전체를 노랗게 채우지 않고 외곽선 위주에 노란 뱃지/부분 포인트를 쓴다. 그래서 `outline + 뱃지`가 가장 가깝다.

## 공식 아이콘/일러스트 안내

- 아이콘 영역은 가로세로 180px이며 상하좌우 적절한 여백을 포함해 제작한다. 이미지는 우측 20px, 하단 16px 여백을 두고 위치한다.
- 아이콘 포인트 색은 브랜드 대표색 1개를 권장한다.

## 검증 방법

```bash
node scripts/validate-image.mjs out.png
```

검사 항목: 형식(PNG/JPG), 500KB, 2:1 비율과 최소 크기, 투명 픽셀 없음, 네 모서리 `#F9F9F9`, 배경색 비율.
공식 PSD 샘플과 대조해 텍스트 위치가 약 1px 이내로 맞는 것을 확인했다(배송완료 샘플 기준 잉크 y 265 vs 공식 263.7, 카카오맵에서 샘플 y 54 vs 54.4).
`lib/draw.mjs`의 `BASELINE_SHIFT`(-3)가 이 대조에서 얻은 보정값이다.

## 불확실한 항목

- Sketch 텍스트 프레임 폭이 540인데 가이드 도판은 520이다. 렌더러는 520을 쓴다.
- 로고형 "25px 영역 추가"의 정확한 의미(위·아래 각각인지)는 공식 PSD/Sketch에서도 확인되지 않았다.
- 텍스트 폭이 공식 샘플보다 1~2.5% 좁게 나온다(렌더러 차이로 추정, 줄바꿈 판단에는 영향 없음).
